Selected work — the network

A foundation two clouds and a datacentre share

Two legs beside this section, either can fail — that is the shape of it.

Every team solved connectivity its own way, and there was no highly available path between Google Cloud, on-premise and the second public cloud.

I led the build of a redundant interconnect foundation with geo-redundant failover, and a pattern that lets spoke networks attach to it without bespoke work. I own its infrastructure as code and the cloud-side configuration; the architecture was co-designed with one other engineer, whom I mentored through it.

It runs in production carrying live workloads, with automatic failover across regions, headroom to scale, and a measurable latency improvement on the traffic it already moves.

Cloud Interconnect, Cloud Router, VPC, Terraform

Selected work — the policy

Egress policy that runs inside the request

The block on the route is the decision. Nothing leaves the path to make it.

Traffic arriving over Private Service Connect cannot be attributed to the consumer behind it, so egress policy could not be enforced per consumer. I proved the managed options could not do it before building anything.

I designed and built a control plane that identifies each connection's consumer, resolves its place in the resource hierarchy, and evaluates allow-or-deny in-process inside the proxy — fail-closed by default, with no network round trip on the decision path. Other teams adopt it through a Terraform provider I wrote, so it looks like adopting any other resource.

Live in development and production on a two-region Kubernetes deployment, run hands-off with GitOps and metric-driven autoscaling.

Envoy, WASM policy filters in Rust, Go, PostgreSQL, Kubernetes, Flux

Selected work — the path in

One route for every new project

Three ways in, one way through. There is no side entrance.

New cloud projects, their Terraform workspaces and their infrastructure repositories were created ad hoc, with no consistent folder or labelling model to inherit.

I designed the automated path they all take now — creation, labelling, perimeter placement, workload identity federation, multi-environment support, group membership — and the API in front of it.

Every new project goes through it. Hundreds of applications have been provisioned on one uniform model.
